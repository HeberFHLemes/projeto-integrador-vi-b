# Características do aplicativo

## Requisitos de usuário

| ID | Requisito | Descrição |
| --- | --- | --- |
| RU01 | Gerenciar agendamentos | O usuário deve poder cadastrar, consultar, editar e cancelar agendamentos. |
| RU02 | Gerenciar clientes | O usuário deve poder cadastrar, consultar, editar e desativar clientes. |
| RU03 | Gerenciar serviços | O usuário deve poder cadastrar, consultar, editar e desativar serviços oferecidos pelo estabelecimento. |
| RU04 | Consultar agendamentos por período | O usuário deve poder visualizar os agendamentos organizados por dia, semana ou mês.
| RU05 | Consultar histórico de agendamentos dos clientes | O usuário deve poder consultar o histórico de agendamentos de cada cliente. |
| RU06 | Acompanhar faturamento | O usuário deve poder consultar o faturamento obtido com os serviços realizados em determinado período. |
| RU07 | Acompanhar fidelização | O usuário deve poder identificar os clientes mais frequentes do estabelecimento. |

---

## Requisitos não-funcionais

| ID | Requisito | Descrição |
| --- | --- | --- |
| RNF01 | Funcionamento _offline_ | O aplicativo deve funcionar sem necessidade de conexão com a _internet_. |
| RNF02 | Persistência local | Deve ser utilizado um banco de dados local (no dispositivo do usuário) para a persistência dos dados. |
| RNF03 | Plataforma | O aplicativo deve ser desenvolvido para dispositivos móveis, especificamente Android. |
| RNF04 | Usabilidade | O aplicativo deve apresentar interfaces simples e intuitivas, facilitando sua utilização. |
